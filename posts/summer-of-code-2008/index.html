Summer of Code 2008

March 26, 2008

  • english

So I submitted my idea for GNOME’s Summer of Code this year… aaaaaand, it doesn’t seem to be very popular as it is currently categorized as “Underground Ideas”. :)

Titled “Enhance Damned Lies and integrate it with open-tran.eu”, it basically tries to lure someone with time to add a little bit of pizzaz to a site that I regularly use in order to proceed with my translations. Now, no offense intended but how can something like “Individual Workspace Wallpapers" be considered as "Rockstar Ideas" compared to the benefits of improving the work flow of those who deliver a GNOME Desktop completely translated every single release cycle? sigh

Anyhow, those of you who are interested in the same idea and want to help expand it a bit more in order to get more attention, please chime in.
